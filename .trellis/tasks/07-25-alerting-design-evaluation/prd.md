# 评估告警设计方案

## Goal

评估一套用于重要业务事件和业务超时的告警设计，明确最小可行的
接口边界、投递可靠性要求、与既有观测的关系，以及适合当前项目的
成熟方案。

## Confirmed Facts

- 后端是 FastAPI、SQLModel/PostgreSQL；已有 `httpx`、SMTP、Sentry 和
  `structlog`，当前没有消息队列、任务调度器或常驻异步 worker。
- `app.utils.send_email()` 已通过 SMTP 投递邮件，并在 SMTP 失败时记录
  `dependency.failed` 观测事件。
- 既有观测仅允许固定、脱敏的运维事件；已完成的 D-002 明确规定未来的
  告警契约不得写入该事件模型，也不得在该任务中加入适配器、收件人、
  重试或站内通知。
- AI 编排调用已有 90 秒硬超时和慢依赖观测阈值；“慢”不等于已经定义了
  需要通知的业务超时策略。
- 用户要求告警设计以接口形式支持邮件、企业微信、飞书、钉钉和站内通知，
  并希望评估两到三个成熟方案。
- 告警服务对象是运维/业务负责人；主要接收点为值班群或固定负责人。企业
  微信、飞书、钉钉的 Webhook 是主要投递渠道，邮件是兜底渠道。站内通知
  仅用于应用用户的待处理事项，不属于本次处置型告警的首期范围。
- 首期不需要人工确认、值班排班、升级链路或未恢复提醒；只要求投递成功/失败
  可追踪，以及按告警指纹去重和限频。
- 首期告警规则由拥有业务语义的代码显式触发；阈值和渠道目标通过启动时
  环境变量配置，不提供应用内规则管理、参数 API 或运营配置页面。
- 生产后端以四个 Uvicorn worker 运行；进程内轮询无法提供单次领取或重启后
  的可靠投递语义。当前依赖、Docker Compose、部署文档均没有 Celery 或 Redis
  服务。
- 用户明确首期没有具体业务事件或超时规则；告警能力作为后续业务异常通知的
  预留接口，而不是现在可投递的功能。
- 已确认的未来运行时方案是 Celery + Redis + PostgreSQL outbox：业务事务写入
  待投递事实，提交后按 outbox 标识入队，Celery Beat 补投未入队或可重试记录。
  既有后台任务边界要求任务仅接收可序列化值，并在任务内创建 session、重载记录。

## Requirements

- 给出推荐的告警事件、渠道和投递边界，避免业务调用方依赖具体通知渠道。
- 区分业务告警与运维/性能告警，并说明与现有结构化观测的衔接方式。
- 评估至少两个成熟方案及其适用条件、运维成本与迁移路径。
- 明确当前阶段的最小实现范围和明确推迟的能力。
- 为主业务事务与外部通知故障定义隔离边界，避免任一渠道失败影响主业务。
- 定义后续实现的渠道无关接口、事件最小字段、可靠投递规则和安全边界；首期
  不加入没有调用方的 Celery、Redis、outbox、环境变量或渠道适配器。
- 首个已批准的业务事件实现时，使用 Celery + Redis 异步投递和受限重试，使用
  PostgreSQL outbox 覆盖提交成功而入队前失败的窗口；任务不得携带 ORM 对象或
  敏感渠道凭据。

## Initial Scope Boundary

- 本任务评估并形成设计结论，不实现告警功能、不修改运行时配置或部署。
- 本任务不实现运行时告警能力，也不新增 Celery、Redis、outbox、渠道凭据或
  应用配置；产出可供首个业务场景直接采用的设计契约。

## Acceptance Criteria

- [x] 设计明确业务事件、超时检测、告警路由与各渠道投递的责任边界。
- [x] 推荐方案可映射到当前仓库的真实能力，并说明未具备的运行时依赖。
- [x] 设计包含去重、频控、失败重试、敏感数据和可观测性的最低要求。
- [x] 首期不要求人工确认、值班排班、升级链路或恢复通知，并将这些能力明确
  记录为后续迭代条件。
- [x] 首期规则无需应用内管理；业务代码拥有触发语义，环境变量拥有阈值和
  渠道目标。
- [x] 设计规定 Celery 任务仅接收可序列化标识或命令负载，Redis 不保存告警业务
  事实或渠道凭据。
- [x] 设计规定 PostgreSQL outbox 覆盖提交后、入队前失败，Celery Beat 补投
  对应记录。
- [x] 结论列出实施前仍需确认的产品决策和后续扩展触发条件。

## Deferred Implementation

后续在首个拥有者、阈值、接收人和处理策略已批准的业务事件中，才引入
Celery、Redis、PostgreSQL outbox、渠道适配器和相应运行时配置。
