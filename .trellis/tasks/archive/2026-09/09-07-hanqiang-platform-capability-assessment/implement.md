- 检查 Markdown 链接和代码路径是否有效。

- 运行 `git diff --check` 和 `git status --short`，确认仅有任务规划与评估文档变更。

## 4. 回滚点

- 本任务无业务代码和数据库变更；如评估结论需要重做，只需修改或删除新增评估文档及任务文档。
