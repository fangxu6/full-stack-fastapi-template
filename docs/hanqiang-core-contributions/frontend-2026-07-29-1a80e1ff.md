## 链路查询契约

- 有 `correlation_id` 时生成 `correlation:<UUID>`；没有时使用 `event:<EventID>`，`aggregate_id` 和 `trace_id` 只用于筛选/定位。
- 列表通过 `GET /api/service-communication/chains` 查询，详情通过 `GET /api/service-communication/chains/{chain_key}` 查询；`statuses` 使用重复 query 参数，Axios 配置 `paramsSerializer: { indexes: null }`。
- 链路状态按后端归并结果展示：`dead`、`paused`、`processing`、`delivered`、`processed`、`ignored`、`cancelled`；不要在前端重新推导整链状态。
- 展开面板只接收轻量记录引用；打开详情时才按 `owner_service_code/direction/event_id` 请求完整记录和载荷。
