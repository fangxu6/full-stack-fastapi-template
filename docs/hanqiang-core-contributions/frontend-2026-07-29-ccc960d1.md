## 变更契约

### 共享状态机

`useImportPreviewDialog` 新增 `importCompleted: Ref<boolean>`，与 `selectedFile`、`previewRows`、`importResult` 同属一次导入会话：

```text
打开/关闭弹窗 -> resetImportState -> idle
选择文件 -> 清空旧结果、importCompleted=false、parsing=true
解析成功 -> previewRows=rows、parsing=false -> ready
确认提交 -> importing=true
  ├─ commitImport 成功 -> 保存 importResult、importCompleted=true
  │    ├─ onCommitSuccess 返回 mergedRows -> 保留结果行，completed
  │    └─ onCommitSuccess 未返回行 -> 调用方可关闭弹窗并 reset
  └─ commitImport 失败 -> onCommitError，importCompleted 保持 false，可重试
重新选择文件 -> 清空旧会话并回到 parsing/ready
```

确认入口必须同时具备两层保护：

1. 组件层把 `importCompleted` 纳入 `confirmDisabledValue`，顶部和底部确认按钮都禁用；完成态确认按钮显示 `completedText`（默认“导入已完成”），上传按钮显示 `reselectFileText`（默认“重新选择文件”）。
2. composable 层在 `importing` 后检查 `importCompleted`。即使调用方绕过了禁用属性再次调用 `confirmImport()`，也只提示“当前文件已完成导入，请修正失败行后重新选择文件再导入。”，不会再次调用 `commitImport`。

`handleFileSelected()` 会在每次文件变更事件中清空 `previewRows`、`previewError`、`importResult` 并重置完成态；因此“重新选择”是新的前端导入会话。该 guard 是会话级交互保护，不是文件哈希或后端幂等键校验；若目标项目要求跨刷新、跨标签页或跨客户端去重，仍需后端幂等策略。

### 产品与 Tooling 的结果处理

- `useFtProductImport` 和 `useToolingImport` 均把失败行与后端返回结果合并后返回 `mergedRows`；`fail_count > 0` 时刷新列表但保留弹窗，摘要追加“请修正失败行后重新选择文件再导入”。
- `fail_count === 0` 时提示成功、刷新列表并关闭弹窗；关闭动作调用 `resetImportState`，下一次打开不会继承完成态。
- 解析阶段的前端字段校验仍只是预览提示，后端逐行校验和导入结果仍是事实源；完成态不能替代后端事务/幂等控制。

## 跨项目复用步骤

1. 把 `useImportPreviewDialog<Row, Result>` 放在共享前端层，要求调用方注入 `parseFile`、`commitImport` 和可选的成功/失败回调；不要在共享层写业务字段映射或具体 API。
2. 在导入弹窗增加可选 `importCompleted`、`reselectFileText`、`completedText` props，并让所有确认入口共享同一个禁用计算值。
3. 让文件变更处理器先清空上一会话的结果，再开始解析；提交成功后先保存结果、再置完成态，失败时不要误标记完成。
4. 业务适配层在后端返回失败行时合并逐行错误并返回新行数组，从而让用户在同一弹窗核对；只有无失败时才关闭弹窗。
5. 页面 composable 和页面 mock 同步透传 `importCompleted`；新增一个组件完成态测试和一个 composable 重复提交测试即可覆盖核心契约。
6. 若目标项目已有后端 `X-Idempotency-Key`、批次号或导入记录，应继续保留；前端完成态只负责减少误点击，不能作为数据一致性边界。

## 历史边界

- 本提交只改变前端导入预览弹窗的会话状态和重复确认交互，不新增 API、数据库约束或后端幂等能力。
- `JseImportPreviewDialog` 的其它消费者（例如题目导入页）仍可使用自己的导入状态；迁移时应逐个确认其关闭、失败行和结果保留策略。
- `src/services/tooling.ts` 中若存在请求级幂等键属于其它提交/服务契约，不能用本提交的 `importCompleted` 替代。
