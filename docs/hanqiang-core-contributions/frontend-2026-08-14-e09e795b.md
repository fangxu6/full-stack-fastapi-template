## 主要改动契约

### HTTP Profile 编辑器

`ExternalIntegrationHttpProfileEditor` 通过 `v-model` 接收完整 `executionTemplate`，通过 `buildExecutionTemplate()` 返回校验后的对象。编辑器把高风险结构化字段收敛为固定边界：

- URL 模板、HTTP 方法（`GET/POST/PUT/PATCH/DELETE`）和正数超时秒数；
- Header 键值非空、键名不重复，值必须是 JSON 字符串或受支持的原始模板表达式；
- Body 可为空，否则必须是有效 JSON；
- 成功 HTTP 状态码限制在 `100..599` 的整数并去重；
- 出站查询至少维护 `equipment_code`、`mes_state` 结果字段映射；事件映射必须属于当前事件契约，源值/目标值长度不超过 255；
- 响应 Header 名称和 Body JSONPath 不允许空值或重复值；
- 高级兼容 JSON 只能提供对象，禁止直接编辑 `sensitiveBindings`/`sensitive_bindings`，保存时从 `protectedTemplate` 恢复受保护绑定。

读取旧配置时兼容 camelCase 与 snake_case（如 `targetUrlTemplate/target_url_template`、`responseProfile/response_profile`、`bodyTemplate/body_template`），写回沿用已有键名并删除过时的事件映射别名，避免同一语义出现两份事实源。预览使用去敏后的模板，不能把密钥绑定回显到页面。

### 统一对话框与页面组合

`ExternalIntegrationCenter` 将配置编辑、回调编辑、入站 Key 轮换、连接预览/测试、审计详情和网络尝试详情统一放入 `PmsDialogShell`；页面草稿仍由页面统一拥有，子组件只通过 `v-model`/事件回传，关闭时不覆盖乐观锁版本或最新草稿。`before_snapshot_masked`、`after_snapshot_masked` 只用于审计展示，保持脱敏对象可见。

## CodeGraph 调用链证据

```text
ExternalIntegrationCenter
  -> useExternalIntegrationRecords
     -> externalIntegrationService (configs/callbacks/logs/attempts/statistics)
  -> ExternalIntegrationCallbackEditorForm
     -> ExternalIntegrationHttpProfileEditor
        -> useExternalIntegrationHttpProfileEditor
           -> parse/build/validate executionTemplate
  -> PmsDialogShell
     -> config / key rotation / callback test / audit / attempt dialogs
```

服务层所有管理请求使用 `disableRetry: true` 和 `skipBusinessErrorMessage: true`，因为配置、Key 轮换和审计操作不可由网络层自动重放；页面统一通过 `resolveApiErrorMessage` 显示错误。

## 跨项目复用步骤

1. 先定义外部集成 Profile 的最小字段白名单和敏感绑定边界，再将表单拆成“可编辑字段 + 受保护模板”两个输入。
2. 将 JSON、Header、状态码、结果映射和事件映射校验集中在 composable/纯函数中；页面只负责草稿、权限、保存和错误提示。
3. 对旧版本字段提供明确的 camelCase/snake_case 读取兼容，写回时选定一个规范键名并删除旧别名。
4. 所有会产生审计事实或外部请求的 service 调用禁用自动重试；预览必须脱敏，测试才允许执行网络请求。
5. 用一个通用 Dialog Shell 承载不同编辑内容，统一 `modelValue`、`closeable`、`close-on-click-overlay` 和 footer 契约。
6. 测试必须包含恶意/错误输入、敏感字段不回显、旧字段兼容、配置快照展示和每个高风险动作的错误路径。

## 历史边界

- 本提交主要重组前端组件和表单校验，不新增外部集成 API，不改变后端认证、回调执行或网络策略。
- `PmsDialogShell` 只统一视觉和关闭交互，不隔离页面状态；草稿所有权仍在页面。
- `disableRetry` 防止不可重放操作被自动重发，但不会替代服务端幂等、乐观锁或审计事务。
- 图标注册只增加展示能力；未注册的图标仍应在图标测试或运行时检查中暴露，而不是静默替代。
