## 根因与修复边界

公共样式将 `.jse-modal-overlay` 和 `.jse-dialog-overlay` 固定为 `z-index: 2600`，而 Element Plus 的 `ElMessageBox`、`el-select` 下拉等弹层从同一页面的 2000 段递增。自定义遮罩打开后，后打开的 Element Plus 弹层反而会被遮罩盖住。

本提交新增 `useOverlayZIndex`，在弹窗打开时从 Element Plus `useZIndex().nextZIndex()` 申请层级，并将结果写回遮罩的 inline style。这样“后打开”的自定义弹窗、确认框和下拉共享一条递增序列。修复只处理层级分配，不改变弹窗业务、关闭行为或 Element Plus 组件本身。

## `useOverlayZIndex` 契约

```ts
const { overlayZIndex } = useOverlayZIndex(visibleOrGetter)
```

- `visibleOrGetter` 可以是 `ref`、computed 或 `() => boolean`；内部用 `toValue` 统一读取。
- `visible` 从 false 变为 true 时才申请新值；初始关闭状态保持 `undefined`。
- 关闭不会回收层级；再次打开会申请更大的值，保证同一实例重开后位于旧弹窗之上。
- Element Plus 正常可用时，调用 `useZIndex().nextZIndex()`，与 MessageBox、Select、Popover 等弹层共享计数器。
- 测试环境若 mock 掉 `element-plus` 或 `useZIndex`，捕获异常并从 2600 开始递增，保证组件仍能挂载和测试。

遮罩必须显式绑定：

```vue
<div v-if="visible" class="jse-dialog-overlay" :style="{ zIndex: overlayZIndex }">
  ...
</div>
```

仅引入 composable 而不绑定 style 不会改变实际层级；只给内容容器设置 z-index 也不能覆盖遮罩的 stacking context。

## 跨项目复用步骤

1. 先搜索所有自定义遮罩（`.jse-modal-overlay`、`.jse-dialog-overlay`、Teleport 到 `body` 的弹窗），确认是否存在固定 z-index。
2. 将层级申请封装为项目级 composable；参数接受 `MaybeRefOrGetter<boolean>`，让不同弹窗的 `modelValue`/`visible` 形状都能接入。
3. 先修改通用弹窗基座，再给不经过基座的自定义弹窗绑定 inline z-index；不要在每个业务弹窗复制计数器。
4. 若弹窗内部使用 Element Plus Popper 组件，优先让其继承同一 `useZIndex` 上下文；只有无法继承时才使用局部 `el-config-provider`，并记录固定值的适用范围。
5. 保留遮罩默认 z-index 作为未挂载/过渡期 fallback，但生产路径必须确认 Element Plus `useZIndex` 可用。
6. 最后验证嵌套场景：自定义弹窗 → `ElMessageBox`、自定义弹窗 → `el-select`、连续关闭再打开，以及两个独立弹窗交错打开。

## 复用时的边界与风险

- `useOverlayZIndex` 的 fallback 序列在每次 composable 调用内从 2600 开始；它只用于测试/缺失依赖时的可挂载性，不提供跨实例的全局排序。若目标项目生产环境可能缺少 Element Plus，应改为模块级共享分配器或注入平台层 allocator。
- `InstructorBindingDialog` 的 2700 是本提交保留的局部 workaround，不是通用默认值；复制到其他弹窗会重新制造固定层级冲突。
- 仍使用固定 `.el-message` 或 `.el-popper` 全局 `!important` 只能掩盖部分顺序问题，不能替代共享计数器。
- 页面若使用多个独立 UI 库，每个库都有自己的 z-index 管理器时，需要统一入口或明确层级区间，否则“共享”只在 Element Plus 内成立。
- CodeGraph 显示当前仓库仍有未接入 helper 的自定义 overlay；迁移前必须以目标项目的实际搜索结果补齐清单，不能只复制本提交列出的培训文件。

## 历史边界

- 本提交没有改动弹窗的 props、事件、业务请求或关闭策略。
