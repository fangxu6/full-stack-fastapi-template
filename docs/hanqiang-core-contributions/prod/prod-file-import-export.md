# prod：文件导入、导出与安全存储

## 目标与非目标

提供受控上传、解析、导出下载和可恢复的文件生命周期。非目标是复制 FTP/业务 DataFile 目录、允许任意本地路径或一次性建设文件监控平台。

## 所有权与数据流

文件元数据、内容存储、导入批次和解析结果分别由文件/业务模块拥有；请求只登记元数据和任务，Worker 读取授权后的文件引用。导入必须有批次 ID、原始文件摘要、解析版本、行级错误和最终状态。

## 安全边界

文件名、路径、扩展名、大小、MIME、压缩层级和内容类型均在信任边界校验；存储路径由服务端生成，禁止路径遍历。下载按资源授权返回，`Content-Disposition` 文件名需安全编码，不能通过 CORS 泄露敏感头。外部 FTP/HTTP 只经白名单 Adapter。

## 幂等、并发与失败恢复

上传/导入以租户、业务批次和内容摘要构造幂等边界，重复提交返回既有批次或明确拒绝。MD5/哈希只作去重辅助，不能替代授权和内容校验。解析失败保留可下载错误报告；临时文件有清理任务和失败告警。

## 观测、配置与迁移

记录批次、文件 ID、大小、耗时、行数、失败类别和操作者，不记录文件正文。存储根目录、保留期、最大大小、并发和外部连接凭据配置化。迁移先双读元数据/目录，再切换写入，回滚保留旧目录只读窗口。

## 测试验收

覆盖空文件、超限、伪造扩展名、恶意路径、重复上传、部分失败、权限下载、断点/重试、并发导入、文件清理和跨环境隔离；前端验证提交防抖、进度/错误反馈和导出文件名。

## 下一任务拆分与运维检查

立项任务至少拆为存储引用/保留期、上传下载 API、导入批次与解析 Worker、错误报告和前端 client 五步；运维检查临时文件积压、存储容量、失败批次、清理任务和下载审计。若只有单一业务消费者，保留其领域适配器，不抽取万能导入 DSL。

## 发布与回滚

先以只读下载或单一导入格式灰度，确认存储、解析和错误报告指标后扩大范围；回滚停用新格式/入口并保留已登记批次、文件证据和旧目录只读窗口，不删除正在恢复的任务。
