# prod：文件监控与远程抓取安全

## 决策与启动门槛

`defer`。只有存在长期、明确的外部文件来源，且普通上传/导入无法覆盖时，才新建任务。前置条件是对象存储策略、资源授权、路径/网络安全策略、处理容量和保留期已确认。

## 目标与非目标

目标是在受控目录或已批准远端获取文件、匹配规则、触发业务处理并保留审计。非目标是扫描任意磁盘、接受任意 URL/正则、执行任意回调代码，或先建设管理页面再确认来源。

## 所有权、数据与接口

监控配置拥有者定义 source、授权范围、匹配规则、处理器版本和保留期；文件处理器拥有幂等摘要、状态和错误。接口只接受结构化策略和已注册处理器，不接受 Python 导入路径、shell 命令或原始 SQL。

## 安全、并发与恢复

本地路径必须规范化后仍位于允许根目录；远端 URL 校验协议、解析后的 IP、端口、重定向、DNS 重绑定、响应大小和超时。正则有长度/复杂度限制和超时；压缩包、防病毒和内容类型按风险另立策略。处理通过内容摘要、来源版本和租约去重；失败可重试并保留隔离文件，不能重复执行业务副作用。

## 观测、配置、测试与发布

记录来源、文件 ID/摘要、规则版本、处理状态、耗时和错误类别；告警包括扫描停滞、拒绝率、隔离量和重复率。配置/凭据来自密钥管理，测试覆盖 path traversal、SSRF、ReDoS、重定向、DNS、超限、重复文件和 Worker 崩溃。发布先在只观测/隔离模式验证，回滚关闭新 source 并保留证据。

## 启动门槛、后续拆分与运维检查

只有明确来源、容量、对象存储和资源授权后才建独立任务；任务至少拆为来源 Adapter、安全校验、扫描/租约、处理器注册、隔离恢复和管理查询。运维检查来源可达性、拒绝/隔离量、扫描延迟、存储容量和规则超时；未满足门槛时禁止创建配置页、调度器或宽松 fallback。

## 迁移与回滚

先以只观测/隔离模式验证来源和规则，再启用业务处理；新处理器与规则绑定版本，迁移期间保留旧来源引用和文件证据。回滚停用新 source 或处理器版本，不删除隔离文件、审计和可恢复任务。
