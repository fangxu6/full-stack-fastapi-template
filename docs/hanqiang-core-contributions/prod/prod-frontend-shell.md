# prod：前端应用壳与交互韧性

## 目标与非目标

复用模板已有的 app/platform/features/shared 分层、薄路由、集中 guards/navigation、生成 OpenAPI client，并吸收 Tab、列表刷新、懒加载恢复、剪贴板、弹层和导入反馈的韧性约束。非目标是复制 Vue 页面布局、把业务组件塞入 shared，或为每个组件增加包装层。

## 所有权与契约

`app/*` 拥有应用壳、导航和全局 provider；`platform/*` 拥有平台能力；`features/*` 拥有业务页；`shared/*` 仅接收已被多个域证明无业务耦合的组件。路由保持薄，权限 guard、菜单和按钮使用一致的服务端权限事实。

## 交互状态与安全

列表刷新、Tab 缓存、导入提交、动态模块重试和弹层 z-index 都必须是显式状态；恢复动作不能重复提交或丢失用户输入。前端错误提示不泄露凭据和内部 URL，下载文件名来自服务端安全响应头，权限只控制可见性而不替代 API 授权。

## 幂等、观测与配置

重复点击、Tab 返回刷新和懒加载恢复必须有一次性状态或请求去重；关键交互记录可关联的错误类别和 Request ID，不记录 token/敏感表单。API base URL、功能开关和重试上限来自环境配置，不能由页面隐式覆盖。

## 测试与发布

用生成 client 保持 API 类型一致；测试覆盖路由保护/菜单一致、Tab 返回刷新、重复导入、懒加载失败恢复、剪贴板降级、弹层键盘可达性和遮罩层级。新页面先放在所属域，只有第二个消费者出现才提取 shared。发布对路由/类型变更运行 lint/build，回滚可移除新导航项且不破坏深链。

## 迁移、回滚与运维检查

路由/权限迁移先保留旧入口兼容窗口，再切换菜单和生成 client；回滚移除新入口并保留深链错误页和旧 API 兼容。运维检查前端资源版本、懒加载失败率、API 错误/401/403 比例、Tab 缓存异常和构建产物完整性。
