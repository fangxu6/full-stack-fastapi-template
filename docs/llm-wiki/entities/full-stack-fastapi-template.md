# full-stack-fastapi-template

## Summary

`full-stack-fastapi-template` is a FastAPI + React repository evolving from a generic template into an enterprise scaffold with explicit backend, frontend, documentation, and AI workflow boundaries.

## Current Shape

- Backend: [[docs/llm-wiki/entities/fastapi-backend|FastAPI backend]]
- Frontend: [[docs/llm-wiki/entities/react-frontend|React frontend]]
- Workflow: [[docs/llm-wiki/entities/trellis|Trellis]]
- Long-term knowledge: `docs/私域知识/**`, `docs/私域知识工程体系产出/**`, and this `docs/llm-wiki/**` layer.

## Key Constraints

- Do not treat template-era shortcuts as the target architecture.
- Preserve existing Trellis task workflow.
- Keep runtime business code separate from AI-maintained knowledge pages.
- Use `ARCHITECTURE.md`, backend/frontend architecture docs, and private-knowledge architecture docs as the first architecture sources.
