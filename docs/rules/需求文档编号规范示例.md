```markdown
# 邮件接收功能 - 业务概述

## 版本信息

- **文档版本**：v1.0.0
- **制定日期**：2025-12-15
- **最后更新**：2025-12-17
- **文档状态**：已确认

## 功能背景与目标

### 背景
当前系统需要支持从企业邮箱接收邮件，并将邮件自动归档到系统中供用户查询、分类与处理。这对于提高信息流转效率、避免重要邮件遗漏至关重要。

### 目标
1. **实时邮件接收**：从指定的企业邮箱账户实时接收邮件
2. **智能分类**：根据邮件发送者、主题等自动分类邮件
3. **高效查询**：支持多维度的邮件查询与搜索
4. **完整归档**：保存邮件的完整内容与附件，支持长期检索

## 业务价值与适用场景

### 业务价值
- **提高沟通效率**：避免邮件在多个应用间散落，统一在系统内查看
- **保证信息完整性**：确保重要邮件不会遗漏
- **便于审计追溯**：所有邮件均有完整的接收、读取、处理记录

### 适用场景
- 财务部：接收发票、财务报表邮件，用于自动化入账
- HR部：接收招聘投递、入职申请邮件
- 销售部：接收客户邮件，与 CRM 集成处理
- 管理层：接收关键决策相关的邮件通知

## 主要参与角色和用户群体

| 角色 | 职责 | 权限范围 |
|------|------|--------|
| **邮箱管理员** | 配置邮箱账户、管理接收规则 | 系统级配置、账户管理 |
| **部门主管** | 查看部门相关邮件、审核分类规则 | 部门级邮件查询、规则审核 |
| **普通员工** | 查看个人相关邮件、进行邮件操作 | 个人邮件查询、邮件操作 |
| **系统管理员** | 监控系统运行状态、处理异常 | 系统级监控、故障处理 |

## 功能与其他模块的关联关系

### 直接依赖
- **文件监听系统**：邮件通过 FTP 文件监听方式实现实时接收（见 [201_后端概述.md#跨功能依赖](./201_后端概述.md#跨功能依赖)）
- **权限管理**：使用系统的 RBAC 权限体系进行邮件访问控制

### 间接集成
- **审批流系统**：当邮件包含审批单据的附件时，需要关联查询（见 [203_邮件解析逻辑.md#与审批流的交互](./203_邮件解析逻辑.md#与审批流的交互)）
- **通知模块**：当新邮件到达时，向相关用户发送通知
- **报表系统**：支持邮件相关的统计与报表生成

## 版本变更日志
```

### 202_邮件接收逻辑.md

```markdown
# 邮件接收功能 - 邮件接收逻辑

## 功能描述

本模块负责从邮件源接收邮件、验证邮件有效性、进行分类、存储到系统，以及更新相关状态。

## 数据操作

### 涉及表
- [Sys_Email_ReceiveHistory.md](../../../dataDict/Sys/Sys_Email_ReceiveHistory.md) - 邮件接收历史
- [Sys_Email_Config.md](../../../dataDict/Sys/Sys_Email_Config.md) - 邮箱配置

## 业务规则

1. **重复检查**：同一邮件（由 Message-ID 标识）不应重复接收，若检测到重复，更新接收历史的状态为"已跳过（重复）"
2. **分类规则**：
   - 若发送者邮箱在白名单中，自动分配到对应分类
   - 若主题包含关键词，自动分配到对应分类
   - 若无法自动分类，分配到"待分类"
3. **异常邮件**：
   - 邮件来自黑名单的发送者，自动标记为"垃圾邮件"，不保存内容只记录日志
   - 邮件大小超过限制，拒收并记录告警日志

## 接口定义

### ReceiveEmail 接口

**请求方式**：POST  
**接口路径**：`/api/email/receive`  
**功能**：接收邮件，执行分类与存储

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| messageID | string | 是 | 邮件唯一标识 |
| from | string | 是 | 发送者邮箱地址 |
| to | string | 是 | 收件人邮箱地址 |
| subject | string | 是 | 邮件主题 |
| body | string | 是 | 邮件正文 |
| receiveTime | datetime | 是 | 接收时间 |
| attachmentNames | string[] | 否 | 附件名称列表 |

**正常返回（HTTP 200）**：
\`\`\`json
{
  "code": 200,
  "message": "邮件接收成功",
  "data": {
    "emailID": "uuid-xxx",
    "category": "销售邮件",
    "receiveStatus": "已分类"
  }
}
\`\`\`

**异常返回示例**：

| 错误码 | HTTP 状态 | message | 说明 |
|--------|---------|---------|------|
| 400001 | 400 | 邮件已存在（重复） | 同一 messageID 已接收过 |
| 400002 | 400 | 发送者在黑名单中 | 邮件被标记为垃圾邮件 |
| 400003 | 400 | 邮件大小超过限制 | 邮件未保存 |
| 500001 | 500 | 数据库保存失败 | 系统内部错误 |

---

## 异常处理

- **邮件重复**：记录日志但不中断流程，返回 code=400001
- **黑名单邮件**：记录告警日志，标记为垃圾邮件，不保存邮件内容
- **大小超限**：拒收邮件并发送通知给管理员
```

- **101 → 102**：业务概述引用流程图
