# ralph-plan 使用说明

## 作用

`ralph-plan` 是一个规划类 skill。它的作用不是直接写代码，而是把模糊需求整理成结构化执行计划，方便后续实现。

## 适用场景

当你遇到这些情况时，适合先用它：

- 需求范围比较大
- 改动跨前后端或跨多个模块
- 想先拆任务再实施
- 想让 Codex 先给出可验证的实施步骤

## 使用方法

### 方法 1：直接在对 Codex 的请求里点名

```text
使用 ralph-plan 先帮我做一个实施计划，再开始编码。
```

```text
使用 ralph-plan 把这个需求拆成 setup、tasks、testing 三部分。
```

### 方法 2：先查看 skill 原文

```bash
npx openskills read ralph-plan
```

## 推荐提问模板

```text
使用 ralph-plan，为“给系统增加 SSO 登录”做一份可执行计划，要求包含背景、准备步骤、任务拆分和验证方法。
```

```text
使用 ralph-plan，把这个重构需求拆成一组低风险、可逐步验证的任务。
```

## 它会怎么组织输出

它通常会把计划拆成这些部分：

- `background`
- `setup`
- `tasks`
- `testing`

核心目标是：

1. 先澄清目标
2. 再补齐缺失约束
3. 再结合代码库现状拆任务
4. 最后给出验证方式

## 在本项目中的建议

- 适合在大改动前先跑一遍。
- 对跨 `backend/` 和 `frontend/` 的需求尤其有价值。
- 它本质上是“规划前置 skill”，适合在真正写代码前使用。
