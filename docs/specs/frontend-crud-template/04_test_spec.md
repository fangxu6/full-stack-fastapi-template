# Test Spec - 前端 CRUD 开发模板

## Validation Scope
- 验证 CRUD 模板是否来自当前前端真实实现，而非通用化建议。
- 验证模板是否能覆盖新增一个典型列表页的主要组成部分。

## Review Checklist
- TC1: 模板中的目录结构可映射到 `Items` 或 `Admin` 现有实现。
- TC2: 模板中的 query/mutation、表单和 DataTable 模式符合当前项目技术栈。
- TC3: 模板明确要求加载态、空态、错误态和成功/失败反馈。
- TC4: 模板与 `docs/rules/前端开发规范.md` 没有重复冲突，而是形成上下位关系。
- TC5: 模板中的命名、导入、生成客户端和禁改目录要求与现有规范一致。

## Manual Verification
- 阅读模板后，应能直接按文档搭建一个新的常规 CRUD 页面骨架。
- 检查模板是否清晰说明哪些文件“建议有”，哪些文件“必须有”。
- 检查是否限制在“常规 CRUD”范围内，避免误用于复杂业务流程页。
