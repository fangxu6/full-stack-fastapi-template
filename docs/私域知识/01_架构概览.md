## 概览

本项目是一个完整的全栈模板，后端使用 FastAPI + SQLModel + PostgreSQL，前端使用 React + Vite + TypeScript + Tailwind CSS + shadcn/ui，默认提供 JWT 登录、用户与条目管理、邮件找回、Docker Compose 部署与本地开发工作流。

## 组件与服务

- Backend: FastAPI 应用，API 前缀为 `/api/v1`，提供 OpenAPI、Swagger UI、ReDoc。
- Frontend: React SPA，TanStack Router + TanStack Query，使用生成的 OpenAPI 客户端。
- Database: PostgreSQL，SQLModel 作为 ORM。
- Adminer: 数据库管理 UI。
- Mailcatcher: 本地开发邮件捕获。
- Traefik: 反向代理与 HTTPS 终端（生产环境），本地可在 compose.override 中启用。

## 请求流与边界

1. 前端通过 OpenAPI 客户端调用后端 `/api/v1`。
2. 登录接口签发 JWT，前端存储在 `localStorage` 并自动随请求带上。
3. 后端依赖项解析用户身份，按权限返回数据。

## 配置与环境

- 配置集中在顶层 `.env`，由 `backend/app/core/config.py` 解析。
- `ENVIRONMENT` 控制运行模式，`local` 时启用私有调试路由。
- `BACKEND_CORS_ORIGINS` 和 `FRONTEND_HOST` 控制跨域与前端来源。

## 部署形态

- 本地开发以 `docker compose watch` 启动全栈。
- 生产推荐 Traefik + Docker Compose，多环境域名分发。
- CI/CD 由 GitHub Actions 提供基础工作流（测试与发布）。

## 项目初始化

- 支持通过 Copier 生成新项目并自动更新 `.env`。

## 主要目录

- `backend/app`: 后端主代码。
- `frontend/src`: 前端主代码。
- `compose.yml` 与 `compose.override.yml`: 生产/开发编排。
- `docs/私域知识`: 项目内部知识与规则。
