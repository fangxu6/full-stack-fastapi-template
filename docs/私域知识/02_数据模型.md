## 数据库模型（SQLModel）

### User

- `id`: UUID，主键。
- `email`: Email，唯一索引。
- `is_active`: 是否启用。
- `is_superuser`: 是否超级管理员。
- `full_name`: 可选姓名。
- `hashed_password`: 密码哈希。
- `created_at`: 创建时间（UTC，带时区）。
- 关系: `items` 一对多，删除用户时级联删除条目。

### Item

- `id`: UUID，主键。
- `title`: 标题，必填。
- `description`: 描述，可选。
- `owner_id`: 外键，关联 `user.id`，`ondelete=CASCADE`。
- `created_at`: 创建时间（UTC，带时区）。
- 关系: `owner` 指向 `User`。

## API 数据结构

### 用户相关

- `UserCreate`: 新建用户（含密码）。
- `UserRegister`: 注册用户（无需登录）。
- `UserUpdate`: 管理员更新用户（字段可选）。
- `UserUpdateMe`: 当前用户更新个人资料。
- `UserPublic`: 对外展示用户信息。
- `UsersPublic`: 用户列表 + 总数。
- `UpdatePassword`: 修改密码请求体。

### 条目相关

- `ItemCreate`: 新建条目。
- `ItemUpdate`: 更新条目（字段可选）。
- `ItemPublic`: 对外展示条目信息。
- `ItemsPublic`: 条目列表 + 总数。

### 认证与通用

- `Token`: 登录返回的访问令牌。
- `TokenPayload`: JWT 解析后的载荷。
- `NewPassword`: 重置密码的 token + 新密码。
- `Message`: 通用消息结构。

## 约束与默认值

- 邮箱长度、密码长度等校验由 Pydantic/SQLModel 约束。
- `created_at` 统一使用 `UTC`。
