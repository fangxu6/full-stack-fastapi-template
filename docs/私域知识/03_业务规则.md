## 认证与授权

- 登录接口使用 OAuth2 Password Flow，`username` 实际为邮箱。
- 访问令牌为 JWT，过期时间由 `ACCESS_TOKEN_EXPIRE_MINUTES` 控制。
- 所有需要登录的接口都会校验用户是否存在且 `is_active=true`。
- `is_superuser=true` 的用户拥有管理员权限。

## 用户管理

- 仅管理员可读取用户列表与创建用户。
- 普通用户可通过 `/users/signup` 注册。
- 更新个人信息时，邮箱必须唯一。
- 修改密码必须提供当前密码，且新旧密码不能相同。
- 超级管理员不能删除自身账号。
- 通过用户 ID 查询时，只有本人或管理员可访问。

## 条目管理（Items）

- 管理员可读取所有条目。
- 普通用户仅可读写自己的条目。
- 更新或删除条目时会校验条目归属。
- 新建条目时自动绑定当前用户为 `owner`。

## 密码找回

- `/password-recovery/{email}` 始终返回统一消息，避免枚举邮箱。
- 仅当用户存在时发送邮件。
- 重置密码需有效 token，且用户必须启用。

## 邮件能力

- 仅在 `SMTP_*` 与 `EMAILS_FROM_*` 配置完整时启用。
- 测试邮件接口仅管理员可调用。

## 私有接口

- `/private` 路由仅在 `ENVIRONMENT=local` 时启用。
