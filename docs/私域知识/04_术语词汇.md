## 术语词汇

- API_V1_STR: 后端 API 前缀，默认 `/api/v1`。
- JWT: JSON Web Token，用于无状态认证。
- Access Token: 登录后颁发的访问令牌。
- Superuser: 超级管理员用户，具备全局权限。
- Active User: `is_active=true` 的用户。
- CORS: 跨域资源共享配置。
- Traefik: 反向代理与 HTTPS 终端。
- Docker Compose: 本地/生产多服务编排。
- Adminer: 数据库管理 UI。
- Mailcatcher: 本地邮件捕获服务。
- OpenAPI: API 描述规范，后端自动生成文档。
- SQLModel: 基于 SQLAlchemy 与 Pydantic 的 ORM。
- Alembic: 数据库迁移工具。
- TanStack Router/Query: 前端路由与数据请求状态管理。
- Prek: 代码格式化与静态检查工具。
