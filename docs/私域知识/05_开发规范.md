## 环境与工具

- 后端依赖使用 `uv` 管理，目录为 `backend/`。
- 前端依赖使用 `bun`（或 Node.js），目录为 `frontend/`。
- 本地全栈推荐 `docker compose watch`。

## 目录约定

- 后端入口：`backend/app/main.py`。
- 后端路由：`backend/app/api/routes/`。
- 模型定义：`backend/app/models.py`。
- CRUD 逻辑：`backend/app/crud.py`。
- 前端入口：`frontend/src/main.tsx`。
- 前端路由：`frontend/src/routes/`。

## 配置与安全

- 所有运行时配置统一从顶层 `.env` 读取。
- 禁止提交真实密钥，`changethis` 仅用于本地占位。
- 生产环境需设置 `SECRET_KEY`、`POSTGRES_PASSWORD`、`FIRST_SUPERUSER_PASSWORD`。

## 数据库与迁移

- 使用 Alembic 生成迁移：`alembic revision --autogenerate -m "..."`。
- 应用迁移：`alembic upgrade head`。
- 初始化数据通过 `backend/app/initial_data.py` 创建首个超级用户。

## 前后端联动

- 后端 OpenAPI 变更后需重新生成客户端：`bash ./scripts/generate-client.sh`。
- 前端调用 API 时使用 `VITE_API_URL` 指向后端。

## 测试与质量

- 后端测试：`bash ./scripts/test.sh`。
- 前端 E2E：`bunx playwright test`。
- 提交前可运行 `uv run prek run --all-files`。
- 预提交钩子会校验类型（mypy）并自动生成前端 SDK（如已配置）。
