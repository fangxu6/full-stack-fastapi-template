## 专业术语词汇表

### 关键结论

- ✅ 术语覆盖后端、前端、部署与安全边界。
- ⚠️ 业务领域术语较少，需结合实际产品补充。

### 术语标准化与使用规范

| 术语 | 标准定义 | 使用规范 | 常见误用/纠正 |
| --- | --- | --- | --- |
| API_V1_STR | 后端 API 版本前缀 | 统一引用 `/api/v1` | 误用为 `/v1` → 统一为 `/api/v1` |
| JWT | JSON Web Token | 作为访问令牌，不保存敏感信息 | 误用为 Session → 改为无状态令牌 |
| Access Token | 登录后颁发的访问令牌 | 前端保存在 `localStorage`，请求自动携带 | 误用为长期有效 → 需受过期时间控制 |
| Superuser | 超级管理员 | 才可管理用户与访问全量条目 | 误用为普通管理员 → 权限分层需明确 |
| Active User | `is_active=true` 的用户 | 所有鉴权请求必须满足 | 误用为仅存在用户 → 需校验启用状态 |
| CORS | 跨域资源共享 | 由 `BACKEND_CORS_ORIGINS` + `FRONTEND_HOST` 组成 | 误用为单一域名 → 支持列表 |
| OpenAPI Client | 自动生成的前端 SDK | 后端变更后重新生成 | 误用为手写请求 → 建议统一生成 |
| SQLModel | ORM | 负责数据模型与表映射 | 误用为纯 Pydantic → 实际为 ORM |
| Alembic | 数据库迁移工具 | 通过 migration 管理表结构 | 误用为手工建表 → 影响可追溯性 |
| Mailcatcher | 本地邮件捕获 | 仅用于开发环境 | 误用为生产 SMTP → 禁止 |
| Traefik | 反向代理与 HTTPS | 生产环境统一入口 | 误用为业务服务 → 仅基础设施 |

### 术语纠正对照表

| 旧称/误称 | 正确术语 |
| --- | --- |
| 登录 Session | JWT Access Token |
| 用户权限 | 超级管理员权限/普通用户权限 |
| 邮件服务器 | SMTP Provider |
| 前端请求 | OpenAPI Client 调用 |

## 文档维护规范

### 增量更新规则

- 新术语：按“业务术语/技术术语/外部服务术语”归类添加。
- 定义调整：只修改定义列，保留英文标识不变。
- 纠正对照：新增误用必须补充纠正项。
